## 项目背景

- 仓库：`{{REPOSITORY}}`
- 形态：打开即玩的静态 3D 网页游戏，部署到对象存储/CDN。
- 3D 是硬性方向：游戏乐趣必须依赖立体空间、纵深判断、镜头运动、物理交互或三维环境变化。拒绝“2D 玩法套 3D 模型”、伪 3D 背景和只靠美术表现的 3D 化。
- 技术边界：优先原生 HTML/CSS/JavaScript + Three.js；必要时可建议 Babylon.js、轻量物理库或 Web Audio。必须纯前端运行，不依赖后端。
- 资产边界：优先程序化几何体、低多边形造型、自制简单模型或明确可商用的 CC0 资产；避免依赖大量定制模型、骨骼动画和昂贵美术生产。
- 已上线：蘑菇人赛车（街机竞速/漂移）、坦克大战（街机射击/阵地战）。不要再给赛车、坦克、换皮射击等高度相似的创意。
- 目标：质量高、可玩性强、规则容易理解，但具备技巧上限、重玩价值和清晰的反馈。
- 实现者：后续会由 Codex 根据 Issue 独立实现，因此 Issue 必须具体、可执行、可验收。

## 必须执行的研究过程

1. 使用 WebSearch 广泛搜索当前可玩的优秀 **3D 浏览器游戏**、WebGL 实验、Game Jam 作品、独立游戏原型和适合转化为 3D 的经典机制。优先研究无需下载安装、打开即玩的作品。
2. 至少考察 8 个作品或机制，其中至少 5 个必须是真正可玩的 3D 网页作品；实际打开并核对最有价值的来源，不要仅凭搜索摘要判断。
3. 在内部形成至少 5 个 3D 候选，并从以下维度比较：前三十秒吸引力、3D 的必要性、空间可读性、镜头体验、机制深度、重复游玩、桌面与移动端浏览器性能、资产成本、实现风险、原创转化空间。
4. 只选择综合最强的一个。可以借鉴机制设计原则，但不能直接复制名称、角色、美术、关卡或受保护 IP。
5. 参考来源至少来自 3 个有效 URL，尽量包含作品原页或开发者的一手介绍。不要捏造链接，也不要把“搜索结果页”作为来源。

不要在最终输出中暴露思维链。用简洁的“调研结论/选择理由”总结可验证的判断即可。

## 质量门槛

最终创意必须同时满足：

- 一句话就能解释核心动作与乐趣。
- 核心机制离开三维空间就无法成立或会明显失去乐趣；必须明确玩家为何需要判断距离、高度、方向、遮挡、惯性或空间关系。
- 有一个鲜明的核心机制组合，而不是若干常见功能的堆砌。
- 单局约 3–10 分钟，失败后愿意立刻再来一局。
- 同时说明即时反馈、分数/成长、难度曲线和高手策略。
- 镜头方案清晰且不易眩晕，说明跟随、旋转、缩放、碰撞规避或固定视角策略。
- 键鼠与触屏都能合理操作；移动端不能简单照搬键盘操作，若某端体验明显更好，需要坦诚说明。
- 给出可执行的 3D 资产策略、灯光与材质方案，不能把关键美术资产留成“以后再找”。
- 给出明确性能预算：目标桌面端 60 FPS、主流移动端至少 30 FPS，并说明对象数量、阴影、粒子、物理和 Draw Call 的控制方式。
- MVP 能由一个编码 Agent 在合理范围内完成，后续仍有明确的打磨空间。
- 不依赖登录、付费素材、版权角色、外部游戏 API 或长期运行的服务器。
- 与蘑菇人赛车、坦克大战以及历史 Issue 有实质差异。

## Issue 正文结构

正文使用中文 Markdown，必须依次包含：

1. `## 一句话概念`
2. `## 为什么值得做`（含调研结论和选择理由）
3. `## 核心玩法`（规则、玩家目标、失败/胜利条件）
4. `## 3D 体验设计`（三维空间为何不可替代、场景结构、空间读法、镜头、灯光、材质、模型与动画策略）
5. `## 单局循环`（开局、中期、高潮、结算与再来一局动机）
6. `## 操作与反馈`（键鼠、触屏、视觉/音效/震动反馈）
7. `## 深度与重玩性`（计分、风险回报、难度曲线、高手策略、变化来源）
8. `## 美术与声音方向`
9. `## Codex 实现建议`（推荐 3D 技术栈、场景图与状态模型、镜头和物理方案、关键模块、资产加载、对象池、性能预算与移动端降级）
10. `## 实现范围`，分为 `### MVP`、`### 打磨项`、`### 暂不实现`
11. `## 验收标准`，使用可勾选清单，至少 8 条可测试标准；必须包含桌面端 FPS、移动端 FPS、加载失败降级、镜头舒适度和触控可用性
12. `## 风险与降级方案`（必须覆盖 WebGL 兼容性、性能不足、物理不稳定和 3D 资产超范围）
13. `## 参考来源`（每条含作品/文章名、有效 URL、具体借鉴点与明确不复制的内容）

Issue 正文控制在 1800–4500 个中文字符左右，避免空泛形容词。标题格式为：

`[Game Idea] 中文游戏名 — 一句机制钩子`
